# Baby Growth Fruit Assets

This folder is used by the Pregnancy Dashboard baby growth card.

Expected image paths:

- `/baby-growth/poppy-seed.png`
- `/baby-growth/blueberry.png`
- `/baby-growth/lime.png`
- `/baby-growth/avocado.png`
- `/baby-growth/banana.png`
- `/baby-growth/corn.png`
- `/baby-growth/eggplant.png`
- `/baby-growth/squash.png`
- `/baby-growth/papaya.png`
- `/baby-growth/watermelon.png`

Starter SVG placeholders are included with matching names.
The UI tries `.png` first and falls back to `.svg`.
