Add your 3D baby models in this folder to enable real model rendering.

Supported filenames:
- week1.glb ... week40.glb
- week-1.glb ... week-40.glb
- trimester1.glb, trimester2.glb, trimester3.glb (fallback by trimester)
- default.glb (global fallback)

Notes:
- `.gltf` is also supported with the same names.
- If no file exists, the app shows an adaptive procedural 3D fallback model.
