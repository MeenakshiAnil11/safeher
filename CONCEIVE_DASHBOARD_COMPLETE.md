4. **Shows personalized recommendations** for improvement

## 📊 Backend Integration

### API Endpoints Used
- `GET /api/fertility/insights` - Get fertility predictions
- `GET /api/fertility/logs` - Get recent logs
- `POST /api/fertility/logs` - Save daily log
